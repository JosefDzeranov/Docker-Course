# reviews-service

Микросервис отзывов к курсу PRO C#. Docker (школа IRON PROGRAMMER). Один из трех репозиториев системы.
Рядом products-service (каталог товаров), а вся топология системы (docker-compose и nginx) вынесена в
отдельный инфра-репозиторий dockercourse-deploy.

Код сервиса лежит в подпапке `reviews-service/`, полное описание внутри `reviews-service/README.md`.

## Что это за сервис

Небольшой веб-сервис на ASP.NET Core плюс PostgreSQL. Принимает отзывы о продуктах, хранит их в базе
и отдает сводку по продукту. Служит примером контейнеризации в курсе.

## Деплой

На каждый пуш в `main` работает CI (`.github/workflows/deploy.yml`). Он собирает образ из контекста
`./reviews-service`, пушит его в GHCR и на сервере обновляет только свой контейнер через `--no-deps`,
не трогая соседние сервисы. Это независимая выкатка.

## Запуск всей системы

Сервис работает внутри системы, а не сам по себе. Чтобы поднять всю систему локально, возьми
инфра-репозиторий dockercourse-deploy и подними его docker-compose. Reviews-service подтянется готовым
образом из GHCR. Как запустить только этот сервис в одиночку, описано в `reviews-service/README.md`.
